## Как прошивка обрабатывает FS() — из дизассемблера

### При отпускании клавиши FS (строки 1585-1599):

```c
// r65 = 0x06 (тип FS), r64 = индекс
DPTR = (r64 * 2) + 0x0936;  // читает fn-код (старший байт)
R5 = *DPTR;
L0374();  // отправляет fn-код как обычную клавишу через EP1

DPTR = (r64 * 2) + 0x0935;  // читает reg (младший байт)
R5 = *DPTR;
// отправляет и reg тоже
```
### При нажатии с Fn (строки 1696-1710):

```c
if (b26) {  // Fn нажата
    DPTR = (r64 * 2) + 0x0936;  // читает fn-код
    R5 = *DPTR;
    if (R5 == 0xFE) {           // проверка на toggle touchpad
        // специальная обработка
        return;
    }
}
// R5 содержит fn-код → отправляется через L0374 как обычная 
```
